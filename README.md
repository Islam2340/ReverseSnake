# Обратная змейка (Android)

Змейка сама растёт, а съеденное яблоко её укорачивает (−2). Цель уровня — сжаться до длины 2.
Управление — свайпы. Каждый уровень быстрее и начинается с более длинной змейки.

## Сборка
GitHub → вкладка **Actions** → **Build APK** → готовый запуск → **Artifacts** → `ReverseSnake-apk`.
